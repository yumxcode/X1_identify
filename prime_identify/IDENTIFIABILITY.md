# X1 惯性参数可辨识性分析（PRIME 无 mocap 适配）

> 结论：**在当前传感配置（IMU 姿态/角速度 + 关节编码器 + 关节力矩，无基座线运动测量）下，
> 除整机总质量（GRF 通道）外，惯性参数不可辨识。** 本文档给出完整证据链。

## 1. 方法与背景

- 实现遵循 PRIME（arXiv:2605.17681）：log-Cholesky 物理一致参数化、接触 QP
  （Anitescu 锥，κ→∞ 刚性极限）、pinocchio 关节力矩回归子（τ = Y(q,v,a)·p，对 p 线性）。
- 传感差异：论文全部实验（Go2/G1）有 OptiTrack 动捕（12 相机，亚毫米基座位姿）+
  （G1）测力台。X1 真机数据仅 IMU + 编码器 + 执行器力矩。

## 2. 证据链（全部可复现，脚本见 prime_identify/scripts/）

### 2.1 估计器管线自洽性：PASS
- 合成自测（`selftest_sim.py`）：GT 参数下合成 v_out，接受指标（接触一致力矩残差）
  = **9.7**（噪声底）；nominal 参数下 = **67.7**；中点 = 23.9（单调）。
  → 估计目标函数的信号通道开放（`sniff_signal.py`）。

### 2.2 标量可辨识性扫描：FAIL（平坦）
- base 质量 dm ∈ [−2, +3] kg 扫描接受指标（`scan_mass.py`）：82.9–85.9，无谷。
  GT 在 +2.0 kg 处**不是**极小值点。
- 物理解释：刚性接触下，参数变化 → GRF（λ）重解 → J^Tλ 完全吸收参数变化对
  动力学的影响（"外力不变子空间"）。ω = J^T λ 的像空间与参数扰动方向重合。

### 2.3 回归子空间分析：FAIL
- 全行力矩残差回归（固定 λ 线性化）：第一步即 stall（λ 响应抵消改进）。
- null(J) 投影回归（消 λ 的严格子空间）：扰动方向落在投影后方程的近零空间
  （早期版本另有 mask-破坏投影的 bug，修复后结论不变）。
- swing 腿行：摆动腿力矩行经基座加速度耦合 λ 通道（M 非对角），并非无耦合子空间
  （`selftest_swing.py`：膝部 +0.4 kg 扰动恢复 0%）。
- FD 数值优化：接受指标对 90 维 θ 的有限差分梯度被 PGS 求解器数值噪声
  （~1e-7 收敛公差）淹没，且单次评估 ~10 ms → 全维优化不可行（多次超时）。

### 2.4 论文交叉验证
- 论文 G1 实验表（torso 参数恢复）依赖动捕提供的基座线加速度：它使 a_base
  成为**不经过 λ 的独立约束**，破坏 2.2 的抵消。
- 论文未做无动捕设定的辨识实验；其效率数字（80 μs/rollout）基于 C++ 解析梯度链。

## 4. 打破抵消的最小传感增配（建议）

1. 基座线加速度真值（动捕 / 双足里程计融合 VIO）——论文路线；
2. 足端力传感器（六维力）：λ 直接可测，回归子恢复满秩；
3. 固定基座激励实验（起重/悬挂，基座 a 已知）：x1_data 的 13 个单关节
   step 数据集可部分充当，但缺实测关节位置列（仅命令+电流），需重采。
