# X1 Sim2Real 系统辨识路径（现状约束版）

> 状态：**生效中**（持续维护） · 版本 v1.2 · 2026-09-04（v1.1 2026-09-03；v1.0 2026-09-02）
> 约束快照：**无动捕、无固定 base link 工装、仅有吊架**；已有 **1 个稳定行走算法模型**（rl_walk_leg，3 维 cmd_vel）+ 3 个策略 checkpoint 的行走数据（5999/7500/7500dr）。
> 本文档回答一个问题：**在这个装备现状下，数据分析与系统辨识按什么路径走，后续如何随装备升级演进。**

---

## 1. 现状盘点与结论先行

| 资产 | 现状 | 辨识含义 |
|---|---|---|
| 吊架（悬挂） | 有 | 可做：悬空单关节/多关节激励（腿无接触），安全、可重复 |
| 稳定行走策略 | 有（rl_walk_leg） | 可做：全身自然运动数据（SPI 主路线已用） |
| 动捕 | **无** | 基座绝对位姿不可观 → base_pos/base_linvel 代价项必须置 0；质量/质心/惯量只能经 IMU 比力+关节通道间接可观 |
| 固定基座工装 | **无** | "真固定基座"辨识（PACE 前提）当前不成立；悬挂 ≠ 固定（吊架受力和基座晃动会污染数据，已实测：step 数据基座陀螺 1.48 rad/s，固定基座假设 R² 仅 0.19–0.31） |
| IMU（quat/gyro/accel） | 有（100 Hz 日志） | 比力通道可约束基座平移动力学（SPI v13+ 已启用，holdout 比力 RMS 20.2→13.0） |
| 足端力传感 | 无 | λ 不可直接测量 → PRIME 路线的接触 QP 近似（信息量不足，已证伪全身惯性辨识） |

**结论**：当前装备下唯一被验证走通的全身辨识路线是 **SPI（采样式 + IMU 比力替代动捕通道）**；PRIME 回归路线已用 7 项实验证明在本传感配置下惯性参数原理性不可辨识（证据链见 `prime_identify/IDENTIFIABILITY.md`），其 GRF 整机质量估计（37.355 kg，+5.8% vs 名义）仍有效并作为 SPI 结果的交叉参照。

## 2. 辨识路径（按数据类型）

```
                data/raw/（F1 数据观测体系产出）
                │
    ┌───────────┼────────────────────────┐
    │           │                        │
 walk_diag 类  阶跃/激励类            后续新类型
 (100Hz 全身)  (1kHz 单关节)          (bag/DATA-04 等)
    │           │                        │
    ▼           ▼                        ▼
 【路线A·SPI】 【路线B·关节级】      【路线C·待启用】
 全身白盒辨识   M1 回归 κs 锚定       通信/执行误差分离
 (spi_identify/)   (data/derived/)       （需 F1 rosbag 接入）
    │           │
    └─────┬─────┘
          ▼
   identified URDF/MJCF + DR（spi_identify/export/）
          ▼
   gradmotion 远端重训（X1_train 框架）
          ▼
   新 ONNX → F1 motion_control 部署 → 下一轮数据
```

### 路线 A：SPI 全身辨识（主路线，已验证 PASS）

1. **输入**：walk_diag CSV（≥1 条，≥10 s，含 IMU 三轴比力）。
2. **切片**：变时域 clips H~U(1.0, 2.0) s，train/val 划分（val_ratio 0.3）。
3. **辨识空间**：骨盆 log-Cholesky (m,r,I)∈R¹⁰ + 电机 κ×4 组 + κs，物理合理域硬约束（质量 3.0–5.5 kg / com ±0.06 m / 惯量特征值 [0.005,0.38] / 惯量积 ≤0.03）。
4. **优化**：Optuna CMA-ES × MuJoCo 开环回放（初态对齐、实机指令回放、tanh 电机模型）。
5. **完成标准（五项全过才 PASS，`validate_spi.py` 自动判定）**：① holdout 代价 ≤ nominal 70%；② 物理合理域（辨识中量纲归一罚强制）；③ IMU 比力 RMS ≤ min(15, max(15.0, 0.35×nominal))——地板=15.0 即绝对上限（3-seed 再基线：观测带宽 13.10–14.76 占满，单 seed 地板必然 seed 敏感）；④ κs 落在阶跃数据 M1 回归证据带 [0.34, 0.71]（独立于行走数据的交叉校验）；⑤ **CROSS-DATASET**：跨策略数据集（不同策略 checkpoint 采集）上代价比 ≤0.70 且比力 RMS ≤ min(15, max(14.405, 0.35×该集 nominal))——物理参数属于机器人而非策略，过拟合策略特异动力学的参数在此暴露。
6. **产出**：`x1_identified.urdf` / `xyber_x1_identified.xml` / `dr_x1_spi.json`（以辨识值为中心的窄带 DR）。
7. **远端执行**：`gm-run X1_identify/spi_identify/scripts/remote_sysid.py`（退出码 0=PASS）。

当前基准（三档，均在 gradmotion isaac-gym-v19 镜像原生验证；2026-09-03 多数据集轮终判后）：
- **多数据集基准（现行，R9）**：T8 域内再辨识（TASK_20260903_015，train=196.5 s/48 clips，7500+7500dr；量纲归一物理域罚）——骨盆 3.152 kg（域内）、κs 0.370（带内）、holdout eff 0.358 / 比力 13.541、cross（5999+legacy 74.4 s）ratio 0.307 / 比力 13.940；**T9 终判五项全 PASS**（TASK_20260903_073 exit 0）。地板：holdout 15.0 / cross 14.405（3-seed 再基线 2026-09-04，§下沿革）。产物 `spi_identify/results/r9_indomain_params.json`
- **原生单数据基准（R4+R7）**：骨盆 3.428 kg、κs 0.396、四项全过（TASK_20260902_022/034）；R4 参数在新数据上 cross ratio 0.318（T1 验证）
- **F1 v15 交叉基准**：F1 侧参数原生复验 PASS（TASK_20260902_030，两环境互洽）
- 可信度分级：质量/κs/κ_knee 高；质心/κ_hip 中；惯量低（无动捕弱可观）。κs 跨四轮稳定 0.36–0.43；骨盆质量 R4 3.43 / F1 3.78 / R9 3.15（域约束收紧后贴下界，提示单刚体骨盆为已知简化）。
- ACCEL 地板沿革：13.5（F1 v15）→ 13.8（原生 R3-R5）→ 12.7/14.8（R8 多数据集，出域解）→ 14.04/14.24（R9 单 seed）→ **15.0 holdout / 14.405 cross（3-seed 再基线 2026-09-04，现行）**——holdout 观测带宽 1.66 占满至绝对上限（seed 方差主导），cross 带宽仅 0.21（稳定）。

### 路线 B：关节级证据（κs 锚定 + 关节模组辨识，已验证）

1. **输入**：1 kHz 单关节阶跃 CSV（吊架悬空，12 关节各一）。
2. **M1 回归**：τ ≈ α·kp·e + β·kd·q̇ + c → 串联关节有效刚度缩放 α=0.34–0.71（κs 搜索域锚定 + SPI 完成标准 4 证据带）。
3. **关节模组动力学辨识**（`joint_identify/`，2026-09-02 新增，T10 修订）：τ−g(q) = J_eff·q̈ + τc·tanh(q̇/ε) + τv·q̇ + c0（**全部串联关节含陀螺耦合项**——knee gyro_rms 0.29 为串联最大，T10 自 hip-only 扩展）+ 执行延迟互相关 + τ–i 映射；悬空 g(q) 由 mujoco qfrc_bias LUT；GATE-J1..J5 门禁（J2 含 2σ 显著性筛查）；列语义运行时验证（反馈 vs 指令不假设）。终态：J4/J5 PASS，J1/J2/J3 边际 FAIL（见最终报告 §3.2/§3.3）。
4. **后续吊架重采直接复用**（`data/README.md §3`）。

### 路线 C：待启用（依赖上游数据接入）

- **DATA-04 actuator 话题对（1 kHz rosbag）**：通信/执行误差分离（F1 D2 双源交叉原理），可量化 walk_diag 100 Hz 盲区内的执行误差 → 用于收紧 SPI 执行器模型先验。
- **DATA-02 tm_obs bin**：策略观测向量 dump → G0 软件契约对齐校验（观测 51 维逐项一致），辨识前的前置质量门。
- **SPI-Active Stage-2**（`spi_identify/active/` 已就绪）：FIM(tr F⁻¹) + Bézier 命令优化生成最优激励命令。**前置条件：多行为策略（当前 3 维 cmd_vel 激励多样性不足）**。启用时机：上游训练出 WTW 式多行为策略后。

## 3. 数据分析路径（每轮新数据的标准动作）

新数据进入 `data/raw/` 后（上传约定见 `data/README.md §3`），按序执行（全部走远端）：

| # | 检查 | 工具 | 判定 |
|---|---|---|---|
| 1 | 结构完整：155 列字段齐全、timestamp 单调、周期稳定 | prepare 阶段日志（远端） | 周期抖动 <±0.5 ms |
| 2 | IMU 约定：静置/准静置段 imu_accel ≈ Rᵀ·g | `check_imu_convention.py` | z 轴 9.5–9.8 m/s²，逐轴相关 >0.9 |
| 3 | 工况覆盖：cmd 分布、步态相位覆盖、时长 | （prepare 阶段 clip 数） | ≥10 clips / ≥1 工况组合 |
| 4 | 串联关节 effort 非零且非 NaN | parse 阶段 | 逐关节 finite |
| 5 | 悬挂阶跃数据：基座晃动幅度 | 陀螺 RMS（M1 回归附带） | >0.5 rad/s 时该轮降级为参考数据 |

任一不过 → 记录到当轮 methods_log，反馈 F1 侧采集参数，不强行进入辨识。

## 4. 装备升级后的路径演进（预置开关）

| 装备变化 | 打开的路径 | 动作 |
|---|---|---|
| **动捕 / VIO 全局位姿** | 基座平移直接可观 | `x1_spi.yaml` 打开 `cost.base_pos/base_linvel`；`validation.accel_rms_floor` 移除地板分支并收紧 max 至 1.5 → 质量/质心/惯量可信度升至"高" |
| **固定基座工装** | 真固定基座关节级辨识（PACE 前提成立） | 悬空 chirp 激励 + 固定基座回放（`deploy/sim2real/pace_runbook.md` 已有 runbook）；执行器参数 (Ia, d, τf, qbias, Td) 直接满秩回归 |
| **足端六维力传感** | λ 直接可测 | PRIME 路线（`prime_identify/`）可重启：接触力真值消除 λ-π 抵消，全身惯性参数可辨识 |
| **多行为策略** | SPI-Active 主动激励 | `run_active.py` 优化命令序列 → 真机采集 → 回到 run_spi 重辨识 |

## 5. 维护规则

1. 本文档随每次装备/数据/结论变化更新版本号与约束快照。
2. 每轮辨识/分析在 `docs/methods_log.md` 追加记录（方法、数据、任务号、结论）；被验证有用的方法沉淀为脚本并登记在根 README §4。
3. 门禁级结论（PASS/FAIL）只能由已提交、带单测的检查代码产生（`validate_spi.py`），ad-hoc 脚本结论不进交付文档——继承 PRIME 路线的质量教训（`docs/rounds/2026-08-31_prime/DELIVERY.md` §6）。
4. 上游契约（字段/频率/时钟）以 F1 `doc/测试体系/` 为唯一权威，本仓库 `data/README.md` 只做消费者视角映射，发现不一致以 F1 文档为准并在此处登记差异。
