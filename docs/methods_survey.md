# X1 系统辨识方法库（方法调研 × 本地实践整合）

> 状态：**v1.0** · 2026-09-02 · 本文档是"充分收集 + 开发辨识方法"的落点：外部方法调研（15+13 篇文献，两份调研报告全文见 `.meta-agent/research/subtask-0eaacd9c|75d02180/report.md`）与本项目已验证方法的整合、适用性评级与采用决策。
> 约束快照：无动捕、无固定基座工装、无足端力传感；仅有吊架 + IMU（比力/陀螺 100 Hz）+ 关节编码器/电流换算力矩（行走 100 Hz / 阶跃 1 kHz）+ 3 个策略 checkpoint 的行走数据（5999/7500/7500+DR，共 ~270 s）。

---

## 1. 方法全景与评级总表

评级维度：**本约束下的适用性**（数据形态是否匹配、是否有同级实机先例）× **验证严格性**（方法自带何种通过标准）。

### 1.1 整机/全身层面

| # | 方法 | 来源 | 辨识对象 | 需动捕/力传感/固定基座? | 适用性 | 本项目状态 |
|---|------|------|----------|------------------------|--------|-----------|
| W1 | **SPI 采样式仿真辨识**（CMA-ES + log-Cholesky + tanh 执行器模型） | arXiv 2505.14266 (CMU LeCAR) | 基座 m/com/I（10 参数）+ 关节 κ 饱和 | 均不需要 | ★★★★☆ | ✅ **主路线**（M-001，原生 R4/R7 PASS） |
| W2 | **LMI 接触零空间投影辨识**（P·Y·φ=P·Sᵀτ，SDP 物理一致 + CAD 测地正则） | arXiv 2409.09850 (Bonn/TUM, RA-L'25, Spot 实机) | 全身连杆惯性参数 + 关节摩擦（粘滞/库仑联合估计） | 均不需要（只需关节力矩） | ★★★★★ | ⏸ 候选：对 τ 通道已被证伪（EIV/冲击振动），但**关节力矩预测 RMSE** 交叉验证框架已被 SPI 的 tau 代价项部分吸收 |
| W3 | **GRF 平衡整机质量估计**（支撑腿 (Jᵀ)⁻¹τ 反算 GRF → m=ΣFz/g） | IROS'17 / IEEE Access'20 / arXiv 2506.13432 | 总质量 m（+水平质心） | 均不需要 | ★★★★☆ | ✅ 已用（M-004：37.355 kg；本轮扩展 G6 跨数据集一致性） |
| W4 | **KF/RLS 在线质量+质心估计**（单刚体动量方程 Φπ=z） | arXiv 2506.13432 (Go2 实机) | m、h=[mcx,mcy]（cz 不可观） | 均不需要 | ★★★★☆ | ✅ 等价离线版已用（同 W3 方程系）；在线化未启用 |
| W5 | **多动量观测器接触估计**（并行模态观测器 + 马尔可夫融合） | arXiv 2412.03462 (CMU) | 接触模态 + 等效外力 | 均不需要 | ★★★★☆ | ⏸ 候选：SPI 隐式吸收接触；显式接触调度对本数据增益有限（已有 phase 时钟） |
| W6 | **learned simulation 残差**（ActuatorNet/UAN/delta-action） | Sci.Rob.'19 / arXiv 2502.10894 / 2502.01143 | 执行器映射或残差动力学 | UAN 不需要力矩传感；ASAP 原方案需动捕 | ★★★★☆（UAN）/ ★★★☆☆（ASAP 降级） | ⏸ 候选：需要仿真内 RL 训练设施；tanh κ 已是其一阶参数化近似 |
| W7 | **可辨识性理论**（基座参数子集 / 远端子树定理 / 谱秩亏） | Ayusawa IJRR'14 / Wensing RA-L'18 | 理论：什么在此传感配置下原理性不可辨 | — | （理论基础） | ✅ 已用（M-005 证伪链：7 实验证明无基座线运动传感时全身惯性参数不可辨） |

**外部文献的关键警示（已被本项目数据证实）**：
- 总质量不能仅靠无接触动量方程辨识（Ayusawa 定理）——必须锚定接触段（W3 正是这么做的）；
- 平地行走中基座 z 向质心与转动惯量不被激励（Haack 明确假设 cz=0）——与本项目"惯量可信度低"的分级一致；
- 电流力矩估计的摩擦偏置同时污染 GRF 反算与回归 —— 本项目以 M1 回归的 α 带宽做交叉锚定。

## 2. 本项目方法体系（现行，含通过标准）

```
                ┌─ 关节模组层（1 kHz 阶跃 ×12）──────────────────────────┐
                │ J1 M1 回归（κs 锚定带 [0.34,0.71]）                      │
                │ J2 摩擦+惯量+延迟+kt 回归（本轮，GATE-J1..J5）           │
                └──────────────┬─────────────────────────────────────────┘
                               │ κs 证据带（独立于行走数据）
data/raw/ ──┬──────────────────▼──────────────────────────────────────────┐
            │ 整机层（100 Hz walk_diag ×11 条，三策略组）                    │
            │ W3 GRF 整机质量（G4: 35–39.5 kg 带宽；G6: 跨数据集极差≤3 kg）│
            │ W1 SPI 全身辨识（五项完成标准，见 §2.1）                      │
            │ W7 可辨识性证伪链（负结果门卫：新数据先过此检查）              │
            └────────────────────────────────────────────────────────────┘
```

### 2.1 SPI 五项完成标准（本轮升级：4→5 项）

| # | 标准 | 判定 | 依据 |
|---|------|------|------|
| 1 | EFFECTIVENESS | holdout 代价 best/nominal ≤ 0.70 | 防参数仅拟合训练集 |
| 2 | PHYSICAL | 质量/质心/惯量（特征值+惯量积）全在物理合理域 | 防超物理域解（v10 教训） |
| 3 | ACCEL | holdout 比力 RMS ≤ min(15, max(方法学地板, 0.35×nominal)) | 地板=无动捕开环回放可达残差（3 seed 原生再基线） |
| 4 | ACTUATOR | κs ∈ [0.34, 0.71]（阶跃 M1 回归证据带） | 独立数据源交叉校验 |
| 5 | **CROSS-DATASET**（本轮新增） | 跨策略数据集（5999 组+legacy，74.4 s）上代价比 ≤0.70 **且** 比力 RMS 落该数据集自己的双侧界内 | 物理参数属于机器人而非策略——过拟合策略特异动力学的参数在此暴露 |

### 2.2 关节级门禁（本轮新增，GATE-J1..J5）

| # | 门禁 | 判定 |
|---|------|------|
| J1 | 动力学拟合度 | 串联关节 R² ≥ 0.60（knee 目标 0.75；hip 容忍 0.55，基座晃动所致） |
| J2 | 左右对称性 | 同名左右关节 (J_eff, τc, τv) 相对差 < 35% |
| J3 | 增益带宽 | α ∈ [0.34, 0.71] 且与 M1 json 逐关节偏差 < 0.08 |
| J4 | 延迟合理 | 串联关节 delay ∈ [-5, +30] ms |
| J5 | 电流常数 | k_t ∈ [0.5, 2.5] Nm/A 且 R² ≥ 0.9 |

### 2.3 整机质量门禁（本轮扩展：G4→G4+G6）

| # | 门禁 | 判定 |
|---|------|------|
| G4 | GRF 质量估计（legacy 锚点） | 35.0 ≤ m ≤ 39.5 kg，frames ≥ 60 |
| G6 | **跨数据集一致性**（本轮新增） | ≥3 条数据独立估计极差 ≤ 3.0 kg，每条 frames ≥ 60（同一台机器人，估计值漂移即暴露系统性问题） |

### 2.4 外部文献共识的验证标准（本项目采用情况）

- 留出数据多步预测误差（simulation-error criterion）→ ✅ 标准 1/3
- 跨步态/任务 OOD 交叉验证 → ✅ 标准 5（跨策略 checkpoint，比跨步态更严）
- 物理一致性约束（伪惯量正定+三角不等式）→ ✅ 标准 2 + log-Cholesky 参数化内建
- 台秤/已知负载锚点（±3% 目标）→ ⚠️ 未见台秤数据；G6 跨数据集一致性部分替代
- 接触估计 vs 人工标注（>75%）→ ❌ 不适用（无视频标注）

## 3. 采用决策与理由

1. **主路线维持 SPI（W1）**：数据形态完全匹配（状态-动作轨迹+短片段），已有原生 PASS 闭环。升级点=多数据源混合训练 + 跨策略验证（标准 5）。
2. **关节层从 M1（J1）扩展到 J2–J4**：逆动力学真值路线（Sorrentino）证明悬挂+无力传感下摩擦/惯量可辨——这是"关节模组层面充分辨识"的主要增量。
3. **W2（LMI 全身）暂缓**：其唯一独立于 SPI 的增量是全身连杆级惯性参数+摩擦，但本项目 τ 通道已被证伪（EIV/冲击），先验正则会主导结果；待有 1kHz 全身日志（DATA-04 接入）再评估。
4. **W6/J8（学习型执行器）暂缓**：tanh κ 是其一阶近似且已嵌入 SPI 代价；等价增益（MAPE 5%）需 RL 训练设施，性价比低于当前路线。
5. **J5/J6（MOR/差分模型）列为下一轮候选**：J6 的 4 参数差分模型与 M1 同源数据即可拟合，是 SPI 执行器模型的直接升级路径。
