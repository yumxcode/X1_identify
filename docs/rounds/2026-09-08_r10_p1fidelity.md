## 4. 发现

1. **回放保真度确为主导误差源（R-1 干预验证）**：同数据同验证器，仅换回放语义（8 ms 延迟 + 0.2 s 重同步），nominal 参数的 holdout 比力 RMS 从 17.289 → 9.531（-45%）——与 M-010/P0 诊断一致。
2. **ACCEL bar 在本传感配置下不可达（结构性）**：即使 0.2 s 重同步，best 8.708 仍为零模型 0.808 的 10.8×（bar 允许 3×）。比力通道残差由逐步接触冲击瞬态主导（R-1a、M-010 结论 3 互证）——刚体开环回放无法预测该内容。
3. **m–κs 简并跨语义稳定（R-2 干预验证）**：κs 0.370（legacy）→ 0.377（fidelity）几乎不动且双双出带；骨盆质量 3.15→3.28（可辨识量仍是 κs/m ≈ 0.115 一带）。ACTUATOR 门禁的出带不是回放伪影，是结构性简并。
4. cross 比率 0.495（R9 为 0.307）：fidelity 语义下 nominal cross 也从 22.262 → 11.996，比率分母大幅下降导致 ratio 升高但绝对 RMS 改善（13.940 → 11.381）。

## 5. 归因补验（R10V，TASK_20260908_285，已完成）

R9 参数 × fidelity 回放语义的 validate-only（全量日志 `results/remote_logs/R10V_TASK_20260908_285_r9params_fidelity.log`，14:35 终态 exit 1）：

| 量 | R9 参数 @ legacy（P1V9） | **R9 参数 @ fidelity（R10V）** | **R10 参数 @ fidelity（R10）** | 归因 |
|---|---|---|---|---|
| holdout 比力 RMS best | 13.541 | **8.543** | 8.708 | 语义贡献 13.541→8.543（**-36.8%**）；参数贡献 8.543→8.708（**+1.9%，更差**） |
| nominal 比力 RMS | 17.289 | 9.531 | 9.531（逐位一致 ✓） | 语义贡献 -44.9% |
| cross 比力 RMS best | 13.940 | **10.441** | 11.381 | R9 参数同语义下更优 |
| cross ratio | 0.307* | **0.431** | 0.495 | *legacy 代价语义不可比；同语义下 R9 更优 |
| EFF ratio | 0.358* | **0.305** | 0.318 | 同语义下 R9 更优 |
| 判定 | FAIL（ACCEL+ACTUATOR） | FAIL（同两项） | FAIL（同两项） | 两参数集差距为噪声级 |

**结论**：R10 全量再辨识在预测意义上一无所获（同语义 holdout/cross 均被 R9 参数追平或反超）——**accel 大改善全部来自回放保真度语义（0.2 s MS + 8 ms 延迟），与参数无关**；m–κs 简并使再辨识在最优点附近抖动而非收敛到"更好"参数。这是对 R-2（简并）最直接的干预证据。
