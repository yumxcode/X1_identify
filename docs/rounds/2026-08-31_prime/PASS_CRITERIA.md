## 1. 门禁（Gate）条目——全部通过才允许声称"参数辨识"

### G1 估计器正确性（Sim GT 自测，通道 B）
- G1.1 合成数据扰动：base +2.0 kg / COM [0.02, 0, −0.03] m / I×1.2，**及** 左右 knee 各 +0.4 kg / COM [0.01, 0, 0] / I×1.1
- G1.2 质量恢复：每个扰动 body 恢复量 ≥ 50% 且绝对误差 ≤ 0.5 kg
- G1.3 COM 恢复误差 ≤ 20 mm（扰动 body）
- G1.4 惯量增量方向余弦 ≥ 0.7（扰动 body，若该方向可激励）
- **G1 未通过时：不得生成/更新任何"辨识后模型"交付物，不得进入真机结论**

### G2 目标一致性（真机，通道 A）
- G2.1 辨识器优化的目标与验收指标必须是同一个量
- G2.2 验收指标：接触一致的力矩残差 `J(θ) = mean_k Σ_rows [Y p − B u − Jᵀλ_k/dt]²`（trusted rows；λ 由当前 θ 的接触 QP 重解）
- G2.3 PASS 条件：`J(θ_id) / J(θ_nom) ≤ 0.95`（train），且 holdout 不恶化超过 +5%
- G2.4 迭代过程必须单调或带步长线搜索回退

### G3 物理一致性（origin 惯量约定）
- G3.1 检查器：`prime.dynamics.pc_min_eig_params/pc_min_eig_origin`——伪惯量 ℐ 由 **origin 惯性参数**（pinocchio `toDynamicParameters` 语义，已经回归子对 RNEA 的 1e-14 精确匹配验证）构造；ℐ ≻ 0 ⟺ 物理一致。配双向单测（已知 PD 体 PASS / 注入负惯量 FAIL）
- G3.2 名义 URDF：13/13 body ℐ ≻ 0
- G3.3 交付 URDF（若生成）：13/13 body ℐ ≻ 0 且参数管线 round-trip ≤ 1e-9
- ⚠️ v1.0 曾以"13/13 违规（SolidWorks 导出缺陷）"为由交付"修复版 URDF"——该结论是检查器约定 bug（把 origin 惯量当 COM 惯量做了平行轴移位），v1.1 裁决推翻：名义 URDF 本就物理一致，无需修复

### G4 整机质量（GRF 平衡，通道 A）
- 指标：mean(Σλⁿ)/g over 收敛帧（接触 QP 竖直力平衡）；**定版估计器**：固定种子子采样 120 帧（`gm_validate.py`，本地/远端逐位一致）
- PASS 条件：点估计 ∈ [35, 39.5] kg、收敛帧 ≥ 60、分段 bootstrap 95% CI 报告
- 交叉验证（可得时）：整机称重；否则报告与 URDF 名义的偏差及可能来源
- 独立于 G1-G2：不因估计器未达标而失效，但只能声称"质量估计"，不得声称"参数辨识"

### G5 gradmotion 远端验证（通道 C）
- G5.1 远端任务可拉取仓库并运行验证脚本（流程打通）
- G5.2 远端独立复算 G4，与本地（同一脚本同一种子）偏差 ≤ 0.2 kg
- G5.3 若 G1-G2 通过：远端加载辨识模型做仿真对比（否则 N/A，如实记录）
- G5.4 验证记录留档（远端任务日志 + 仓库内 results/gm_validation.json；注：当前 gm CLI 版本无 note 子命令，平台侧笔记不可用，已在仓库内留档）

## 3. 当前状态（2026-08-31 终版 v1.1）

- **G1 FAIL**：sim 自测含腿组扰动，恢复 ~0-3%。根因是**可辨识性物理边界**而非实现缺陷（完整证据链 `prime_identify/IDENTIFIABILITY.md` §2.1–2.7）：① 信号通道开放（GT 成本 9.7 vs nominal 67.7，排除实现缺陷）；② 支撑相：base 质量标量扫描平坦（82.9–85.9 无谷，λ 重解抵消）；③ 结构性：基座参数列在全部关节行上**精确为零**（Newton-Euler 远端子树定理）——无基座传感则原理性不可见；④ 摆动相：行严格无接触但设计矩阵谱秩亏（rank 31/60，GT 增量 99.6% 落在近零空间，cond 6e21）；⑤ 单关节 step 数据基座非固定（陀螺 1.5 rad/s）且仅单关节记录，通道证伪。论文靠 mocap 基座测量打破 ②③。**IMU 加速度计替代路线亦已尝试并证伪**（§2.7：walk_diag 含 imu_accel，三种估计器架构——瞬时 Z 投影/窗脉冲 box 约束/质量标量——均被足端冲击振动（|f| 峰值 34 m/s²）与 EIV 偏差破坏，恢复量符号随机）。软件侧路线至此穷尽。
- **G2 FAIL**：真机回归 train 33283→200142（+501%）。与 G1 同根因。
